# Hissa qo'shish

Yordamingizdan xursandmiz! 🙌

1. Repozitoriyni **fork** qiling.
2. Yangi branch oching: `git checkout -b yangi-imkoniyat`
3. O'zgartirish kiriting va tekshiring:
   ```bash
   flutter analyze
   flutter run -d macos
   ```
4. Commit qiling va **Pull Request** oching.

## Qoidalar
- Interfeys matnlari o'zbek tilida (lotin alifbosi) bo'lsin.
- Dart kodi `flutter analyze` dan xatosiz o'tishi kerak.
- Katta o'zgarishlardan oldin avval **Issue** ochib, g'oyani muhokama qiling.
